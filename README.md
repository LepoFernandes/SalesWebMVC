# 💼 Sales Web MBC

## 🚀 Sobre o projeto

Projeto de sistema de vendas desenvolvido com **C# e SQL Server**, voltado para gerenciar produtos, clientes e vendas.
Foi criado com foco em praticar **programação orientada a objetos**, **manipulação de banco de dados** e **lógica de negócios**.

## 🌐 Demonstração

*(Como o projeto depende de backend e banco de dados local, não há página online disponível)*
👉 [Repositório no GitHub](https://github.com/LepoFernandes/Sales-Web-MBC)

## 🛠 Tecnologias

* C#
* SQL Server

## ⚙️ Como rodar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/LepoFernandes/Sales-Web-MBC.git
   ```
2. Abra o projeto em uma IDE compatível com C# (ex: Visual Studio, Rider ou VS Code com extensão C#).
3. Configure o banco de dados local conforme instruções no projeto (ex: scripts SQL).
4. Compile e execute o projeto (`F5` ou `dotnet run` dependendo da IDE/CLI).

## 📌 Aprendizados

Com esse projeto aprendi:

* Estruturação de um sistema completo com backend e banco de dados
* Manipulação de dados e operações CRUD em SQL Server
* Programação orientada a objetos em C#
